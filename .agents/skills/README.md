# Visualcheme Chemical Engineering Skills & Unit Design Knowledge Base

This knowledge repository compiles fundamental engineering principles, governing mathematical formulations, design procedures, heuristics, and extracted figures from *Chemical Engineering Design: Principles, Practice and Economics of Plant and Process Design* (2nd Edition, Gavin Towler & Ray Sinnott).

It serves as an expert on-demand skill library for LLMs and autonomous agents designing, modeling, simulating, and visualizing chemical process unit operations in **Visualcheme**.

## How to Use in Visualcheme Development
1. **Model Formulation**: Reference the governing equations in the relevant unit skill (e.g. Darcy-Weisbach for pipes, MESH equations for distillation, LMTD/Kern for heat exchangers).
2. **Visual & Didactic Gradient Selection**: Use the physical properties documented in each skill to populate Visualcheme's user gradient selector (e.g., pressure drop, velocity profile, exergy loss, shear stress).
3. **Preset Scenario Calibration**: Use the design heuristics tables to set realistic default dimensions, flows, and operating pressures for demonstration cases.
